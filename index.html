CODAP · Data Point Shape interactive UX prototype — not production CODAP

What to look at: the Format panel on the right of the graph tile. Point Size and Border Color stay global, and each Habitat category gets its own shape and fill, as we agreed on 25 Aug. Everything redraws immediately; nothing is saved.

  • Point Size behaves as it does today — CODAP's computed radius times 0–2. Drag it with different shapes set and watch the small end: Star, Plus and X are the ones that give up first.
  • Legend → No legend shows the panel’s basic form: with no legend attribute there are no categories to list, so the three category rows collapse to a single Points row with the same shape and fill dropdowns. Worth checking that the panel still reads sensibly in the case most CODAP graphs are actually in.
  • Menu width compares Michael’s 216 px Zeplin spec against the 256 px we discussed. Every label now fits at both widths; what changes is the category row — 216 px leaves about 11 characters for a category name before it truncates, 256 px leaves about 16.
  • Click a point to select it (Shift-click to add) — this is how the shapes handle CODAP’s selection styling, a red 2 px border at radius + 1. Clicking a legend key selects that whole category, as it does in CODAP today.
  • Legend keys switches between CODAP’s color squares and keys that carry the shape too. The shape version is a proposal, not something we agreed — it is here to be judged. Either way the keys stay clickable.
  • Docs, top right, has the read me, the design findings, the asset spec and the seven SVGs.

Metrics

Scope of this prototype

  • Formatting is session-only. No CODAP document model, no serialization, no plugin API.
  • Only the Format inspector button opens a panel. Rescale / View / Measure / Image are chrome.
  • Fused points and the fuse-to-bars animation are deliberately out of scope — see FINDINGS.md.
  • Shape geometry is generated from a single library (js/shapes.js) shared by the plotted points, the Point Shape menu and the legend keys; assets/shapes/ holds the exported SVGs.
  • Switch View above to the geometry sheet: every shape at every CODAP point radius, with border behavior and metrics.
