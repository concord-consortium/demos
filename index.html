How to run
  1. From this folder, serve over HTTP: python3 -m http.server 8000
  2. Open http://localhost:8000/index.html in each browser.
  3. For each test row: click BEFORE N, press Tab, note what the tracker shows. Then click AFTER N and press Shift+Tab.
  4. Safari: enable Full Keyboard Access (System Settings → Keyboard → Keyboard navigation) or hold Option while pressing Tab.
  5. Cross-origin variant: append ?xorigin=1 to load the iframes from a second origin that serves the same files, so the parent can't read into them. Locally, localhost and 127.0.0.1 are different origins — open http://localhost:8000/index.html?xorigin=1 and the iframe srcs are rewritten to http://127.0.0.1:8000/.... When deployed, the swap is between models-resources.concord.org and models-resources.s3.amazonaws.com (the demo is published to both). The tracker's inner-element readout will then show "(cross-origin — cannot read inner)" instead of the inner activeElement, matching the AP scenario.
